# Lab 01 — Система банківських рахунків (Варіант 4)

Реалізація системи банківських рахунків відповідно до вимог лабораторної роботи №1 курсу «Професійний Python».

## Структура
- `src/bank_manager/models.py` — датаклас `Account` із валідацією невід'ємного балансу.
- `src/bank_manager/services.py` — бізнес-функції: створення, поповнення, списання, перевірка залишку, пошук та агрегація.
- `src/bank_manager/main.py` — консольний демонстраційний скрипт.
- `tests/test_services.py` — набір тестів `pytest`.

## Запуск тестів
```bash
pytest tests/ -v
```
