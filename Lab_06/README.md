# Lab 06 — Автоматизоване тестування Python-програм (Варіант 4)

Лабораторна робота №6 курсу «Професійний Python».

## Архітектура та організація Test Suite
- Використання фреймворку `pytest` для побудови надійного набору автоматизованих тестів.
- Структурована організація: модульні тести у `tests/unit/` та наскрізні сценарії у `tests/integration/`.
- Ізоляція зовнішніх залежностей (репозиторіїв, поштових/платіжних шлюзів, асинхронних клієнтів) за допомогою `unittest.mock` (`Mock`, `AsyncMock`, `side_effect`, `create_autospec`).
- Ізоляція файлової системи за допомогою вбудованої fixture `tmp_path`.
- Тестування конфігурацій та змінних середовища за допомогою `monkeypatch`.
- Параметризоване тестування граничних значень (`@pytest.mark.parametrize`) та перевірка винятків (`pytest.raises`).
- Вимірювання тестового покриття через `pytest-cov` (>90% branch & statement coverage).

## Запуск тестів
```bash
pytest -v
pytest --cov=application --cov-branch --cov-report=term-missing
```
