# Lab 02 — Аналіз банківських рахунків та декоратори (Варіант 4)

Лабораторна робота №2 курсу «Професійний Python».

## Зміст
- `src/bank_processor/models.py` — типізована структура `AccountRecord` з підтримкою типу рахунку.
- `src/bank_processor/analytics.py` — групування, фільтрація, індексація, обчислення метрик.
- `src/bank_processor/decorators.py` — параметризовані декоратори логування та вимірювання часу.
- `program_output.txt` — результати виконання та аналіз складності алгоритмів.
