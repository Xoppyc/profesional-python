# Lab 03 — Потокова обробка банківських транзакцій та ітератори (Варіант 4)

Лабораторна робота №3 курсу «Професійний Python».

## Архітектура потокового конвеєра
- Ледача обробка генераторами (`yield`) запобігає вичерпанню пам'яті O(1) для великих файлів транзакцій.
- Конвеєрна композиція: `parse_csv_stream` -> `validate_transaction_stream` -> `filter_by_client_stream` -> `batch_stream`.
- Використання `itertools.islice` для оптимізованого порційного зчитування.
